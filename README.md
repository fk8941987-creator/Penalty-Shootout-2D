## About the Game
Penalty Shootout 2D is a browser-based 2D football penalty shootout game built with HTML, CSS, and JavaScript Canvas. The goal of the game is to outscore your opponent in a 5-kick penalty shootout—alternating between taking shots and diving to make saves—and win the match (or survive Sudden Death if tied).

## How to Play
1. Team & Player Setup: Select your country and opponent country from the dropdown menus (or click **Random Opponent**), type custom names for both players, and click 2. Start Shootout.
3. Mouse Move (Shooting Turn): Move the mouse anywhere on the pitch to aim the yellow crosshair and dashed trajectory line.
4. Left Click (Shooting Turn): Kick the ball toward your aimed target.
5. Mouse Move (Goalkeeper Turn): Move the mouse inside the goal area to position the blue dive indicator.
6. Left Click (Goalkeeper Turn): Dive to that spot to attempt a save against the opponent's shot.
